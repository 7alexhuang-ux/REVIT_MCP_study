# 萬用窗 add-in 使用說明

> 對象：不用 AI、只想在 Revit 裡直接生成窗族的同事。
> 狀態：v0.2，**已通過編譯（Revit 2023／2024／2025 設定 0 error）與對話框煙霧測試，尚未在 Revit 內實機驗證**。
> 設計依據：`docs/ADR.md` D-008、`docs/universal-window/SPEC.md` §11。

## 這是什麼

Revit 功能區的「**萬用窗**」面板有一顆「**產生窗族**」按鈕。按下去會開一個對話框，讓你選窗型、調尺寸，按「產生族並載入專案」就會：

1. 用 Revit 的 `Metric Window.rft` 樣板建一個窗族（框、扇、玻璃、開口切透、圖面符號、UW_ 共用參數）。
2. 存成 `.rfa` 檔（預設在 `%APPDATA%\RevitMCP\families\`）。
3. 載入目前開啟的專案，之後就能在「建築 › 窗」直接放置。

**不需要**開啟「MCP 服務 (開/關)」，也不需要任何 AI。AI 客戶端用的 MCP 工具 `generate_window_family` 與這個對話框共用同一個生成引擎（`MCP/Core/WindowFamily/`），兩邊產出相同。

## 使用步驟

1. 開啟（或新建）一個專案。要載入族就必須在專案裡；在族編輯器裡只能生成 `.rfa` 檔。
2. 功能區 › 「萬用窗」面板 › 「產生窗族」。
3. 左上「範例窗型」挑一個起點（共 10 個：上固定下外推、橫拉窗、固定窗、上窗、下窗、三樘組合、三軌橫拉含紗窗、垂直上下拉、下懸內倒氣窗、上中下三排）。
4. 調整「尺寸與格子」：排數（1–3）、樘數（1–4）、總寬、總高、窗台高、排高比、樘寬比。
   - 比例可以只填到倒數第二個值，最後一個自動補滿 100（例：2 排填 `35` → `35 : 65`）。
   - 也可以填任意比例，會自動縮放到 100（例：`1 : 2` → `33.33 : 66.67`）。
5. 在「格子」小地圖點選一格，編輯：
   - 扇數（1–4）。
   - 每扇型式：固定、外推、橫拉、上懸、下懸／內倒、垂直上下拉、紗窗。
   - 鉸鏈左／右（只有外推）、開向（外推／上懸／下懸可選向內、向外；下懸預設向內＝內倒）、軌序（橫拉類，0＝最外軌，「自動」由引擎分配）。
   - 規則：橫拉、垂直上下拉、紗窗屬於「滑動類」，同一格必須整格都是滑動類；橫拉與垂直上下拉不可同格；紗窗不能單獨成格。違反時對話框右下方直接顯示錯誤。
6. 「框料與玻璃」：外框寬、中框寬、扇框寬、框深（預設 7 cm）、玻璃厚、交疊（預設同扇框寬）。
7. 「族名與輸出」：預設勾選「自動命名」，族名會是 `UW-R{排}C{樘}-{型式縮寫}`（例 `UW-R2C2-F-CL-CR`），型別名是 `{總寬}x{總高}`（例 `240x180`）。取消勾選就能自己填。
8. 按「產生族並載入專案」。完成後右下方顯示族檔路徑、扇數、玻璃面積、有效採光面積、可開口面積與警告。

右側的**立面預覽**會隨你的每個修改即時重畫（自室外看；虛線＝向內開；橘框＝目前選取的格）。預覽是示意線框，正式圖面表示由生成的族負責。

## 常見訊息

| 訊息 | 原因 | 怎麼辦 |
|---|---|---|
| 找不到窗族樣板 Metric Window.rft | Revit 的族群樣板路徑沒設或樣板沒安裝 | 選項 › 檔案位置 › 族群樣板檔案預設路徑 |
| 專案內已有同名族 | 之前已載入過同名族 | 勾「同名族已在專案內時覆蓋」，或換族名 |
| 淨寬／淨高算出非正值 | 總尺寸太小，扣掉框料後沒剩 | 加大尺寸或縮小框寬 |
| 目前沒有開啟中的專案文件 | 沒有開專案 | 開專案，或取消勾「生成後載入目前專案」 |

## 已知限制

- 尚未在 Revit 內實機驗證：族幾何、載入、對話框在 Revit 裡的行為都要實測後才算完成（見 ROADMAP Phase 1）。
- 對話框是 modal：生成期間 Revit 會暫時無回應，通常數秒到十幾秒。
- 目前只有「單窗生成」。從 Excel 門窗表批次生成、窗型庫管理是 SPEC §11 列的後續功能，尚未做。
- 功能區按鈕圖示是程式繪製的簡易窗形圖示，之後可換正式美術。
