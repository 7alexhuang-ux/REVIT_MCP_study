## 2. 國際分類

### IfcWindowTypePartitioningEnum（11 值）
SINGLE_PANEL、DOUBLE_PANEL_VERTICAL、DOUBLE_PANEL_HORIZONTAL、TRIPLE_PANEL_VERTICAL、TRIPLE_PANEL_BOTTOM、TRIPLE_PANEL_TOP、TRIPLE_PANEL_LEFT、TRIPLE_PANEL_RIGHT、TRIPLE_PANEL_HORIZONTAL、USERDEFINED、NOTDEFINED
來源：https://steptools.com/stds/ifc/html/t_ifcwindowtypepartitioningenum.html（IFC4 版，實抓）。IFC4.3 官方頁（standards.buildingsmart.org）回 403，由搜尋摘要確認 4.3 值相同，未逐字核對官方頁。VERTICAL／HORIZONTAL 與格子方向的對應需實作時對官方圖確認。

### IfcWindowPanelOperationEnum（14 值）
SIDEHUNGRIGHTHAND、SIDEHUNGLEFTHAND、TILTANDTURNRIGHTHAND、TILTANDTURNLEFTHAND、TOPHUNG、BOTTOMHUNG、PIVOTHORIZONTAL、PIVOTVERTICAL、SLIDINGVERTICAL、SLIDINGHORIZONTAL、REMOVABLECASEMENT、FIXEDCASEMENT、OTHEROPERATION、NOTDEFINED
來源：https://docs.xbim.net/XbimDocs/documentation/Xbim.Ifc4/Xbim.Ifc4.Interfaces.IfcWindowPanelOperationEnum.html（實抓，IFC4 介面；4.3 官方頁 403，未核對是否有增減）。

### 歐美常見
- 美式：single hung、double hung（可內傾清潔）、casement（側鉸鏈外開）、awning（頂部鉸鏈）、hopper（底部鉸鏈，多數來源說內開）、slider、picture/fixed、bay（中央固定＋兩側約45度斜翼）、bow（4扇以上連續轉折）。來源：https://www.angi.com/articles/window-types-your-home.htm 、https://www.archtoolbox.com/types-of-windows/（僅搜尋摘要，未逐字抓取）。
- 歐式 tilt-and-turn、pivot：本次只確認 IFC 有對應值，工程細節未查證。

## 4. 窗型系統分類建議

格子生成器定位為「矩形平面窗」，優先順序：

1. **維持 v1**：固定、外推、橫拉、上懸（覆蓋台灣最常見組合）。
2. **同生成器小擴充（最先）**：(a) 橫拉 3–4 扇與三軌（track 改整數）＋紗窗 `screen` 扇；(b) 下懸／內倒（`hopper`＋`swing`）；(c) 垂直上下拉 `sliding_v`。
3. **同生成器 Phase 3 配件**：外推窗紗窗（隱藏／捲軸／摺疊）、防墜、tilt-turn、pivot。
4. **另立 louver（百葉）生成器**。
5. **另立凸窗／轉角窗組合工具**：以格子窗為子單元，加外挑箱體或夾角座標。
