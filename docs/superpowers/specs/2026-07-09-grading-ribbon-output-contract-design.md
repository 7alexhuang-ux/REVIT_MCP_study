# 整地 Ribbon 出圖契約設計

日期：2026-07-09

## 背景

整地圖說 Ribbon 目前有兩個容易混淆的出圖入口：「比較出圖」與「方案成套圖」。使用者確認新的產品語意如下：

- 「比較出圖」保留名稱，代表多方案橫向比較。
- 「方案成套圖」改名為「各別出圖」，代表每個方案各自排圖。
- 兩者都必須完成排圖紙、輸出 PDF、輸出 Excel，不允許只有其中一部分。
- 缺少圖框 family 不得導致出圖失敗。
- 每次按出圖按鈕都要讓使用者選擇圖框。

## Ribbon 順序與命名

整地圖說面板前段依主工作流排序：

1. 新整地方案
2. 整地檢視
3. 方案總覽
4. 六級坡度
5. 比較出圖
6. 各別出圖
7. 板高程斜板
8. 邊坡率

所有 Ribbon 文字不得主動帶 `...` 或 `…`。若 Revit 因面板寬度自動截斷，仍需盡量使用短雙行文字降低截斷機率。

## 六級坡度按鈕

新增「六級坡度」Ribbon 按鈕。按下後列出所有登記簿方案，使用者選擇目標後，系統在方案視圖或專用視圖上執行 `create_slope_heatmap`，產生台灣水保六級坡 AVF 熱區。此按鈕是即時檢視工具，不負責排圖或輸出 PDF。原地形六級坡仍由「比較出圖」的原始地形基準欄自動生成。

## 比較出圖

「比較出圖」是多方案決策輸出：

1. 每次按鈕都跳出圖框選擇。
2. 使用者可選模型內任一圖框，也可選「無圖框空白圖紙」。
3. 預設選項優先 A0；沒有 A0 時選第一個可用圖框；完全沒有圖框時預設空白圖紙。
4. 建立或更新總比較圖紙，一欄一方案，含原始地形基準欄與各方案欄。
5. 輸出合併 PDF。
6. 輸出方案比較 Excel。

## 各別出圖

「各別出圖」是每方案獨立輸出：

1. 每次按鈕都跳出圖框選擇。
2. 使用者可選模型內任一圖框，也可選「無圖框空白圖紙」。
3. 預設選項優先 A0；沒有 A0 時選第一個可用圖框；完全沒有圖框時預設空白圖紙。
4. 每個方案各排一張圖紙。
5. 所有方案圖紙合併輸出為一份 PDF。
6. 輸出方案比較 Excel。

## 圖框 fallback

不得因模型沒有 TitleBlock family 而中止出圖。

圖框選擇採三層策略：

1. 使用者明確選擇圖框：使用該 `titleBlockId`。
2. 使用者明確選擇空白圖紙：用 Revit 空白 Sheet 建圖。
3. 模型無可用圖框：自動使用空白 Sheet 建圖。

不自動產生 title block family，避免污染模型與造成公司圖框樣式不一致。空白 Sheet 仍需完成 viewport 排版、PDF 匯出與 Excel 匯出。完成訊息需指出本次是否使用空白圖紙。

## Excel 契約

比較出圖與各別出圖第一階段共用同一種「方案比較 Excel」資料來源，避免 PDF 表格與 Excel 數值不同源。輸出檔名可依入口區分，但欄位與計算邏輯一致。

## 錯誤處理

- 圖框缺失：不得失敗，改用空白 Sheet。
- PDF 匯出失敗：命令回傳成功/失敗物件，訊息中明確列出 PDF 錯誤，但不影響已建立圖紙與 Excel。
- Excel 匯出失敗：命令回傳成功/失敗物件，訊息中明確列出 Excel 錯誤，但不刪除已建立圖紙或 PDF。
- 單一方案視圖建立失敗：各別出圖延續既有逐方案容錯，其他方案繼續。

## 驗收條件

- Ribbon 前段順序與命名符合本文件。
- Ribbon label 不含 `...` 或 `…`。
- 模型沒有圖框 family 時，「比較出圖」仍可建立空白圖紙、排版、嘗試 PDF、輸出 Excel。
- 模型沒有圖框 family 時，「各別出圖」仍可建立空白圖紙、排版、嘗試 PDF、輸出 Excel。
- 使用者每次按「比較出圖」與「各別出圖」都會看到圖框選擇對話框。
- `比較出圖` 回傳中含 PDF 與 Excel 結果。
- `各別出圖` 回傳中含 PDF 與 Excel 結果。
