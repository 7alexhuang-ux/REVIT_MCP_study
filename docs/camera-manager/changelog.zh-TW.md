## 2026-09-25

### 21:16｜MCP 測試工具（Wave 1）＋文件拆分
- 新增 5 個 MCP 工具：`list_cameras`、`run_camera_keyplan`、`set_camera_pose`、`copy_camera_to_level`、`get_view_extents`（工具數 212 → 217），呼叫面板用的同一套服務程式碼（D-023）。
- 面板內的「開啟並排 4 視圖」「關閉其他視圖」「清單編輯請求組裝」移到 `CameraManagerService`，面板改為轉呼叫（行為不變）。
- 一鍵 4 視圖可接受單次覆寫的剖面方向／等角範圍（只給 MCP 用，不寫回設定），並在回傳值附上關鍵判定。
- 規格書拆成 `docs/camera-manager/` 下的 spec／adr／changelog／roadmap 四份；舊檔改為轉址說明。

### 20:55｜commit `6504b52`｜底圖共用挑法、剖面簡化樓層記號、扇形置底
- ③ 底圖挑選改為步驟 0（相機放置時的平面，ES 記錄）→ 同層包含 → ±1.5 m 樓層包含 → 下方樓層包含 → 同層最大，預設／跟隨／選取／精簡清單共用（D-018）。相機落在底圖外時 ③ 顯示提示。
- 剖面淡化樣式整類隱藏樓層，改畫以 ES 連結真實 Level 的簡化樓層記號，Level 改動時自動重畫（D-014）。
- 扇形填滿透明度 70% → 90%，並送到詳圖最底層；楔形與線拉到最上。

### 19:35｜剖面連結樓層、保留樓層標頭、畫面中心、底圖挑最大平面
- 淡化樣式下 Key Plan 平面與剖面的連結改「依主體視圖」。
- 保留樓層改為視圖專屬 2D 範圍、標頭伸出框外 1.5 m（20:55 已被簡化樓層記號取代）。
- 剖面改通過畫面中心線；扇形半徑、視線穿越房間區段改沿中心線。
- 底圖自動挑「包含相機的最大平面」（20:55 擴充為步驟 0–4）。
- 事故：本輪曾用 PowerShell 改寫檔案造成亂碼，已完整復原（`domain/lessons.md` L-032）。

### 15:06｜清單「樓層」欄改樓層＝複製相機
- 取代 14:27 的「就地換樓層＋退役舊 Key Plan 平面」；原相機與 Key Plan 不動（D-010）。

### 14:27｜真標準等角、清單換樓層提交、③ 跟隨新相機、建築樓層判定
- 等角改為 ViewCube 上方四角中最接近相機者（D-011）。
- 樓層下拉提交改為 SelectionChanged／DropDownClosed 先到者一次。
- ③ 跟隨剛放置、尚未進清單的新相機；樓層只認 Building Story（D-020）。

### 12:59｜清單常駐 TextBox、樓層標頭隱藏、③ 跟隨作用中透視圖、底圖清單精簡
- 清單數字欄改常駐 TextBox／ComboBox，不走 DataGrid 編輯模式（D-009）。
- ③ 跟隨作用中透視圖；底圖清單預設只列有相機的樓層，「全」切換顯示全部。

### 06:59｜淡化背景改用類別／元素取代
- Display Model 不再半色調；主要構件剖切線黑、外牆加粗（D-016）。

### 06:51｜室內／室外判定
- 眼睛不在房間＝室外，改用扇形範圍、室外半徑設定（預設 60 m）、等角 Z 由模型最高點決定（D-012）。
- 剖面樓層只留 1～2 個。

### 06:39｜非對稱視錐與眼睛楔形
- 扇形改用左／右／下／上帶號邊界角；朝前三角箭頭改為眼睛楔形（D-025）。

### 01:02｜只用眼睛所在房間、挑高房間頂、剖面方向選項、FOV 讀取修正
- Key Plan 範圍只用眼睛所在房間 +0.6 m；上層樓板只認房間頂以上者。
- 扇形半徑＝視線離開房間距離 +0.6 m。
- 剖面方向新增「對齊房間長邊（預設）／沿視線」（D-013）；「重設剖面到視線」改名「重設剖面位置」。
- FOV 讀取修正（舊版深度正負號錯誤，永遠讀不到）。
- 平面上看不到本相機剖面線：設剖面比例門檻、類別可見、viewer 元素取代。

### 00:27｜箭頭半透明、平面只留本相機剖面、Key Plan 表現法
- 平面 Key Plan 只顯示本相機剖面。
- 新增 Key Plan 樣式（淡化背景／原始）、自動比例。
- 等角打開註解總開關，只留剖面框。
