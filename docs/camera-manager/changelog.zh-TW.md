## 2026-09-25

### 22:50｜MCP 自測第二輪修正（6 項，已編譯、待 MCP 複測）
- **樓梯間／挑空裡的室內相機仍判室外**：眼睛 XY 不在任何房間內時，取水平 ≤ 1.5 m、垂直範圍含眼睛（或差 ≤ 2 m）的最近房間判為室內，log「最近房間 d=…mm」。
- **透視圖看得到 A 標記**：視圖由樣板控制 V/G 時改在樣板上隱藏「相機標記」子類別並記樣板名稱（D-033）；出圖用透視複本也做。
- **扇形不跟子類別隱藏**：扇形 GraphicsStyle 取不到時先 Regenerate；`SetShape` 後讀回確認幾何屬於子類別，不符記在 `AMarkerLog`（扇形原本就以 `SolidOptions` 指定子類別樣式——出現在複本上的主因是上一項的樣板問題）。
- **`markerMode=B` 不刪 A 標記**：一鍵 4 視圖在標記型式不含 A 時刪除這台相機的 A 實例＋扇形。
- **沒動過的剖面被判成「手動移過」**：ES 改存 CropBox 套用後讀回的實際 Transform，角度容許 2°→0.5°，不一致時兩組值都記 log。
- **圖紙排版**：可繪區扣除圖框標題欄（幾何偵測，失敗＝橫式保留右 20 %）；透視左 55 %、右欄列高依內容；Key Plan 視圖自動挑最細標準比例；透視複本等比放大裁剪框填滿格子約 90 %（FOV 讀回驗證）；本相機圖紙上的視埠每次重新排版（D-034）。

### 22:20｜MCP 自測第一輪修正（6 項，已編譯、待 MCP 複測）
- **Key Plan 平面／樓層總覽被 Scope Box 鎖住**：複製來的平面每次先解除 Scope Box、改專案北、移除非矩形裁剪、裁剪框轉正、圖紙上的標題改成「Key Plan 平面」／「樓層總覽 <樓層>」，之後才設裁剪框；裁剪框設完讀回，與預期差 > 1 % 記 WARNING（附原因）；總覽回報的範圍改為讀回值（另列預期值）。
- **室內相機被判成室外**：房間搜尋改為「XY 在房間輪廓內＋垂直範圍含眼睛，否則 ≤ 2 m 最近」，不再依賴下方建築樓層（D-031）。
- **室內相機樓層錯（女兒牆）**：室內相機的樓層＝房間的 Level，離樓板高度以它計算；清單、位置圖、Key Plan、總覽分組、A 標記同源（D-031）。
- **剖面 Key Plan 出現其他剖面標頭**：平面／剖面／總覽逐元素隱藏其他剖面／立面／詳圖索引標記（平面保留本相機剖面），並隱藏立面／詳圖索引類別。
- **一鍵出圖紙略過已在別張圖紙上的透視圖**：改放出圖用透視複本 `<相機名>-Key Plan 圖紙` 並持續同步（D-032）；`ViewportTypeLog` 改列完整候選與「實際使用」的類型（舊版候選清單為空卻說「沒有顯示標題的類型」）。
- **測試工具**：`run_camera_keyplan` 加 `markerMode`（B／A／AB，單次覆寫）並回傳 `MarkerModeUsed`、`Warnings`；`get_view_extents` 加 Scope Box、方位、圖紙上的標題、可見的其他視圖標記數；`list_cameras` 加 `LevelSource`／`LevelByElevation`；`run_camera_overview` 加 `IntendedMm`、`ScopeBox`、`Warnings`；`create_camera_sheet` 加 `Perspective`。工具數不變（220）。
