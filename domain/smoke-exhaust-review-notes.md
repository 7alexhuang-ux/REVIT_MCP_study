# 排煙窗法規檢討工具 — 開發筆記

## 起源

受到 David 的**採光檢討**（`get_room_daylight_info`）啟發，進一步延伸到**排煙窗法規檢討**。
採光檢討已經能取得房間的窗戶面積與採光比例，但排煙窗的法規要求更嚴格 — 不只看窗戶面積，還要看：

- 窗戶位置是否在**天花板下 80cm 範圍內**
- 窗戶是否**可開啟**（固定窗排煙面積 = 0）
- 開啟方式的**折減係數**（橫拉窗只算 50%）

這些是採光檢討沒有涵蓋的，所以獨立做了一套排煙窗檢討工具。

---

## 做法概述

### 核心工具：`check_smoke_exhaust_windows`

**輸入：**
- `levelName`：要檢討的樓層
- `ceilingHeightSource`：天花板高度來源（`room_parameter` 或 `ceiling_element`）
- `colorize`：是否自動上色 + 建立四向立面視圖（預設 true）

**處理流程：**
1. 取得樓層所有房間，排除非居室（走廊、樓梯等）和 ≤ 50m² 小房間
2. 逐房間取得天花板高度，計算有效帶（天花板 ~ 天花板-80cm）
3. 找出每間房間牆上的窗戶，判斷是否落入有效帶
4. 從族群名稱推斷開啟方式，套用折減係數
5. 加總有效面積，與區劃面積 2% 比較
6. 不合規的房間產生具體改善建議

**輸出（per room）：**
- 天花板高度、有效帶範圍
- 每扇窗的尺寸、位置、帶內面積、開啟方式、有效面積
- 合規判定（PASS / FAIL）
- 缺口面積
- 改善建議（含具體窗型和 ID）

### 輔助工具：`check_floor_effective_openings`

判定「無開口樓層」（消防§4），檢查外牆有效開口面積是否 ≥ 樓地板面積 1/30。

### 匯出工具：`export_smoke_review_excel`

匯出 .xlsx Excel 報告，四個工作表：
1. **樓層總覽** — 無開口樓層判定 + 法規依據
2. **房間檢討明細** — 每間房間的有效面積、比值、判定、改善建議
3. **窗戶明細** — 每扇窗的尺寸、位置、開啟方式、折減後有效面積
4. **改善建議** — 不合規房間的具體改善方案 + 可用窗型

---

## 窗戶開啟方式判定

從族群名稱自動推斷，無法判定的標註「需人工確認」：

| 族群名稱關鍵字 | 判定 | 折減係數 |
|----------------|------|----------|
| casement, 平開, 側開, pivot | 全開型 | 1.0 |
| sliding, 橫拉, 推拉, hung | 半開型 | 0.5 |
| awning, 外推, 上懸 | 外推型 | 0.5 |
| fixed, 固定 | 固定窗 | 0 |
| 其他 | 未知 | 0（加註） |

---

## 改善建議的四種提案

不合規的房間會依缺口大小自動產生建議：

### 建議 A：固定窗改為可開啟窗
- 列出有效帶內的每扇固定窗（窗 ID + 類型）
- 查詢專案中已有的 Casement 窗型供替換
- 計算替換後可補足的面積

### 建議 B：窗戶上移進入有效帶
- 找出窗頂距有效帶下緣 30cm 以內的窗戶
- 標出需上移幾 mm 即可計入排煙面積

### 建議 C：新增可開啟窗
- 列出專案中所有可開啟窗型，按有效面積排序
- 標示每扇窗可補足的面積，方便選擇

### 建議 D：改採機械排煙
- 缺口過大或完全無窗時建議
- 提供排煙風機 + 風管方案

## 視覺化（四向立面）

自動複製 N/S/E/W 四個立面視圖，在其上：
- **窗戶上色**：綠=全開型、黃=折減型、紅=固定窗、灰=未知
- **天花板線**（紅色）：標示天花板位置
- **有效帶下緣線**（綠色）：標示天花板 - 80cm 位置
- **標註文字**：天花板高度 / 有效帶 / 下緣高度
- **窗戶帶內標註**：帶內寬×高 = 面積

## 已知問題 & 待改進

### 標示線段雜線
- 天花板線和有效帶線目前畫在每個立面的全寬範圍
- 當不同房間有不同天花板高度時（如 2900mm 和 4000mm），會出現多條線交叉
- **待處理**：應依房間邊界分段繪製，或只在有窗的牆段畫線

### Excel 表格可更清晰
- 改善建議欄位的可用窗型清單目前是文字換行，可改用子表格或分行展示
- 可加入條件格式化（如有效面積不足時自動標紅）
- 考慮加入圖表（如每間房間的 有效面積 vs 需求面積 長條圖）

### 其他待做
- Step 4 防煙區劃自動偵測（目前以單一房間為單位，> 500m² 只標警告）
- 水平距離檢查（任一點至排煙口 ≤ 30m，目前未實作）
- 採光有效係數 L 的乘法（Step 2 的衛生採光要求，與排煙獨立）
