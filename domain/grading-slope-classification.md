# 整地坡度分級標準作業程序（Grading Slope Classification SOP）

## 1. 目的

為整地後的設計地形提供**符合台灣水土保持法規**的坡度視覺化與分級，供山坡地開發之坡度分析與送審參考。對應工具 `create_slope_heatmap`。

⚠️ 本 SOP **只做坡度分級**。土地可利用限度（宜農牧地／宜林地／加強保育地）的完整判定需額外的土層深度與地質調查資料，**非本工具輸出**，詳見 §2.1。

## 2. 權威分類：水土保持技術規範 六級坡

坡度熱區的著色級距一律以此表為準，**不得以模型一般知識替代**：

| 級別 | 坡度範圍 | 屬性 |
|---|---|---|
| 一級坡 | 5% 以下 | |
| 二級坡 | 超過 5% 至 15% | |
| 三級坡 | 超過 15% 至 30% | |
| 四級坡 | 超過 30% 至 40% | |
| 五級坡 | 超過 40% 至 55% | （不得單憑坡度標註，見下） |
| 六級坡 | 超過 55% | 宜林地 |

邊界採**右閉**判定：`≤5→一級`、`(5,15]→二級`、`(15,30]→三級`、`(30,40]→四級`、`(40,55]→五級`、`>55→六級`。實作見純函式 `SlopeClassifier.Classify(坡度%)`（NUnit 覆蓋，零 Revit 相依）。

### 2.1 🔴 屬性欄的法源與禁止事項（2026-09-21 更正）

本節更正本檔 v1.0（2026-07-06）的**錯誤標註**。原表寫「五級坡＝宜林地、六級坡＝加強保育地」，**兩者皆與法規原文不符**，已於 2026-09-21 回查原文更正。

**法源一：山坡地土地可利用限度分類標準 第 4 條**（農業部，民國 109-10-06 修正）

> **宜林地**：應符合下列規定之一，並造林或維持自然林木或植生覆蓋，不宜農耕之土地：（一）甚淺層之四級坡，且其土壤沖蝕嚴重或下接硬質母岩。（二）甚淺層之五級坡。（三）淺層之五級坡，且其土壤沖蝕嚴重或下接硬質母岩。（四）**六級坡**。
>
> **加強保育地**：屬**沖蝕極嚴重、崩塌、地滑、脆弱母岩裸露**之土地。

由原文可得兩條**強制規則**：

1. **只有六級坡無條件屬宜林地。** 四級坡、五級坡是否為宜林地，另須「土層深度（甚淺層／淺層／深層）」「土壤沖蝕程度」「下接母岩硬度」三項條件，**單憑坡度百分比無法判定**。因此四、五級坡的屬性欄一律**留空**，不得由坡度回推。
2. **「加強保育地」不是坡度級別。** 它以地質條件界定，與坡度無關。工具輸出的任何圖例、標籤、報告**都不得出現此詞**，除非另有地質／沖蝕調查資料輸入。`SlopeClassifierTests` 已加入迴圈斷言，任何級別若被標為「加強保育地」即測試失敗。

**法源二：水土保持技術規範 第 23 條**（農業部，民國 114-05-07 修正）

該條的坡度分級表**實為七級**：六級坡為 `55% < S ≤ 100%`，另有**七級坡 `S > 100%`**。本分級器只做到六級並把 >100% 併入六級坡（視覺化用途，不影響級距邊界判定）。若日後要用於水保工程設計（邊坡、整地規範對應），**須補第七級**。

**適用範圍分界（不可混用）**：級距本身兩部法規一致；但「宜林地」判定請引用**山坡地土地可利用限度分類標準**，「工程設計坡度分級」請引用**水土保持技術規範第 23 條**，不要用同一個函式同時宣稱兩種法律效果。

## 3. 坡度計算方法

於設計地形頂面各取樣點以**面法線**求表面坡度，不另建網格：

```
slope% = 100 × √(nx² + ny²) / nz
```

其中 (nx, ny, nz) 為該點朝上單位法線（nz > 0）。近垂直面（nz ≤ 0）不計。此法與 `floor-slope-analysis.md` 的樓板坡度演算法同源（法向量與 Z 軸夾角）。

## 4. 熱區著色

- AVF（`SpatialFieldManager`）以**級別（1..6）為值**寫入，取得離散色帶（非連續漸層）。
- 色帶：一級（綠）→ 六級（紫），對應六級坡各級固定色。
- 圖例列出級別、坡度範圍、屬性與各級取樣點數。屬性欄**僅六級坡標「宜林地」**，其餘留空（理由見 §2.1）。

## 5. 定位與限制

- **僅視覺化定位**坡度分布；**坡度統計權威值以正式水保計算書為準**，工具不重算亦不取代簽證數字。
- 一視圖僅能掛一種 AVF 顯示樣式；坡度熱區與挖填熱區須各自置於不同視圖（出圖協調 `create_grading_presentation` 會自動複製視圖分別著色）。
