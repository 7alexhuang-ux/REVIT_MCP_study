# 方格法土方計算書（Earthwork Gridsheet SOP）

## 1. 目的與定位

把整地方案的挖填量以**格網矩陣**形式呈現，產出可交付、可人工複核的 Excel 計算書。
對應工具 `export_earthwork_gridsheet`。

**定位（不得誤述）：方格法的加總是呈現值，不是權威值。**
正式土方量一律以 Revit 內建 CUT/FILL（即方案登記簿記載值）為準；兩者差額是方格離散誤差，
由總表並列揭露，方格法**不取代**、也不修正登記簿數字。

## 2. 前提

- 必須先有整地方案登記（`RequireSchemeRecord`）——沒有方案就沒有原地形 ID 與正式 CUT/FILL 可對帳。
- 原地形與設計地形都必須有可用實體幾何，否則中止。
- **唯讀操作，全程不開交易**，不會修改模型。

## 3. 格網建立

| 項目 | 規則 |
|---|---|
| 格徑 `cellSizeMeters` | 預設 **10 m**，須 > 0 |
| 格網範圍 | 原地形與設計地形 bounding box 的**交集**（X/Y 各取 max(min) 與 min(max)） |
| 欄列數 | `ceil(範圍 / 格徑)`，各至少 1 |
| 格數上限 | **40000**，超過即中止並要求放大格徑 |
| 無水平重疊 | 直接中止（兩地形不重疊無法建格） |

格數上限是效能護欄：每格要打兩條射線，40000 格即 80000 次求交。

## 4. 取樣法：格中心單點射線

每格取**格中心一點**，垂直向下打射線分別與原地形、設計地形頂面求交：

```
中心點 = (minX + (欄 + 0.5) × 格徑,  minY + (列 + 0.5) × 格徑)
射線範圍 = [兩地形最低點 − 10 ft, 兩地形最高點 + 10 ft]

挖填深 = 原地形GL − 設計GL      （正 = 挖，負 = 填）
```

### ⚠️ 與傳統四角平均法的差異（判讀前必讀）

台灣測量／土木慣例的方格法多採**四角高程平均**（`(h₁+h₂+h₃+h₄)/4`）或角柱法。
本工具採**格中心單點**，兩者在格內坡度變化大時會有系統性差異：

- 格內若為線性坡面 → 中心點值等於四角平均，兩法一致。
- 格內若有轉折（稜線、坡腳、擋土構造）→ 中心單點會偏離四角平均，格徑越大偏差越大。

**因此：格徑必須配合地形起伏選定。** 地形轉折密集處縮小格徑；不得用大格徑掩蓋起伏。
若審查單位指定四角平均法，本工具輸出**不得直接充作該法的計算書**，僅能作為對照。

## 5. 逐格計算

| 情況 | 處置 |
|---|---|
| 兩側射線都命中 | 記 GL 與挖填深，計入取樣格數 |
| **任一側未命中** | 該格深度記 `null`，Excel 顯示「—」，**完全不計入挖或填** |
| 深度 = 0 | 計入取樣格數，但挖填皆不加 |

體積累加（`EarthworkGrid.Compute`）：

```
格面積 = 格徑²
深度 > 0 → CUT  += 深度 × 格面積
深度 < 0 → FILL += (−深度) × 格面積
```

**未命中格不外插、不補值。** 總表同時列出「有取樣格數 / 總格數」，讓審閱者自行判斷取樣覆蓋率；
覆蓋率偏低即代表格網超出地形範圍，應縮小範圍或改格徑重跑。

## 6. Excel 輸出

四張工作表：

| 工作表 | 內容 |
|---|---|
| 原地形GL | 原地形頂面高程矩陣（m，兩位小數） |
| 設計GL | 設計地形頂面高程矩陣 |
| 挖填深 | 挖填深矩陣；挖為粉底（#FCE4EC）、填為藍底（#E3F2FD），門檻 ±0.005 m |
| 總表 | 方案資訊、格徑、取樣格數、方格法 CUT/FILL、Revit 正式 CUT/FILL、兩者差額（m³ 與 %）、差額性質說明 |

矩陣排列規定：

- 欄標 `C1…Cn` 由西向東；列標 `R1…Rn` 由南向北。
- **Excel 第一列放最北列**（列序反轉），使表格方位與平面圖一致。
- 首列與首欄凍結。

檔名未指定時：`土方計算書_方格法_{方案名}_{yyyyMMdd_HHmmss}.xlsx`，存於專案檔目錄（未存檔的專案則放桌面）。

## 7. 差額判讀

總表的「CUT 差額 / FILL 差額」= 方格法值 − Revit 正式值，同時給絕對值與百分比（正式值為 0 時百分比顯示「—」）。

- 差額來源是**方格離散化**，不是任一方算錯。
- 差額百分比偏大 → 縮小格徑重跑；仍偏大代表地形起伏超出該格徑的解析能力。
- **對外送審與計價一律引用 Revit 正式 CUT/FILL**；方格法矩陣作為佐證與人工複核之用。
